# Trading Cooldown

Drop this folder into `<your world>/datapacks/` and run `/reload` in game.
A green `[VillagerCD] loaded` message confirms it worked.

Shows a floating label above villagers whose trades have sold out, counting down
to the moment the game will allow a restock.

To uninstall: run `/function villagercd:uninstall`, then delete this folder.

Full documentation: https://github.com/Thinnaphat-tht/Trading-Cooldown-Notification
